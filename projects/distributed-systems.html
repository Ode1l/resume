Go Kademlia DHT

Project README / Original Chinese thesis PDF / Original Word document.

Undergraduate thesis implementing PING, FIND_NODE, GET_PEERS and ANNOUNCE_PEER, XOR-distance routing, peer discovery and concurrent queries in Go. Integrated the DHT with a torrent-download session.

The thesis documents query results, Wireshark captures and a torrent download using a third-party download tool. This is distinct from independently implementing the complete BitTorrent stack. The original thesis is in Chinese.

Total-Order Multicast

README and source / Original report / Original submission archive.

Implemented a C# protocol for consistent multicast delivery order across five processes, using logical clocks and ordering messages. A network simulator applies delays; the UI displays message stages for ordering checks.

Completed and successfully assessed postgraduate coursework. Original code uses Windows Forms and a batch launcher; it has not been rerun during this documentation update. No production fault-tolerance or performance claims are made.

P2P Lockstep Kit

A reusable TypeScript/WebRTC session toolkit for deterministic browser games, with session management, reconnect recovery and multiplayer Mahjong. Source / Mahjong demo.

Blockchain-Based Decentralized PKI

Project README / Full original English report.

Using Short Blockchain Systems as Decentralized PKI Infrastructure: a postgraduate research report proposing lightweight blockchain-based certificate issuance, validation and revocation, including smart-contract automation and deployment trade-offs.

Unpublished coursework research, not a deployed blockchain product. Its focus is PKI rather than DNS; proposed security properties are not independently verified guarantees.

ChessServer

Academic C# HTTP/1.1 server using Thread and Socket APIs, including request parsing, concurrent connections, keep-alive, static/binary delivery and multiplayer chess state. Source. No current maintenance or full protocol-compliance claim.
